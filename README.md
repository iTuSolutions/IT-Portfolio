# iT-U Company Website

Complete responsive multi-page corporate website.

## Main features
- Tailwind CSS via CDN
- Font Awesome icons
- Inter font
- Responsive navigation and mobile menu
- Dark/light theme toggle with localStorage
- Corporate homepage
- About, services, solutions, hosting and contact pages
- Web development sub-pages
- Website pricing page
- Blogger and GitHub Pages hosting information
- Demo contact form ready to connect to a form/email backend

## Important before publishing
1. Replace placeholder phone/email/address with the real company details.
2. Connect the contact form to Formspree, Netlify Forms, a backend, or another form provider.
3. Review website package prices and change them to your actual prices.
4. Replace placeholder portfolio/case-study content with real projects.
5. The site currently uses Tailwind CSS from the CDN, so internet access is required for the styling to load.
